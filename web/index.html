Convertly

Convert images and documents, and edit PDFs — entirely inside your browser.

Not built yet

This is the browser build. The structure is in place; the conversion code is being ported. The macOS app is ready to use today — see the repository.

How your files will be handled

  • Everything runs in this page. Files are read by JavaScript on your device.
  • There is no server to upload to — this page is static files only.
  • A Content Security Policy blocks any connection off this origin.
  • Once it works offline, you can turn off your network and still convert.

What will work here

  • HEIC, PNG, JPEG, GIF, BMP, WebP → JPG, JPEG or PDF
  • Resizing, and fitting a picture under a size limit
  • PDF pages → images, and pulling pages out of or joining PDFs
  • Pages, Keynote and Numbers, via the preview stored inside them
  • Word files stay in the macOS app — qlmanage has no browser equivalent
No uploads. No accounts. No tracking.
