Keep it under

Quality is lowered first, so the picture keeps its dimensions. Only if that is not enough is it made smaller — and the row tells you which happened. The result is a JPG, because that is the format that can trade quality for size.

Longest edge

The shape of the picture is always kept, and it is never enlarged — ask for more than it has and it is left alone. A PNG stays a PNG so it stays lossless; anything else comes out as a JPG.

Order

Add two or more PDFs. They are joined top to bottom — use the arrows on each row to move one up or down. Pages keep their original quality: nothing is re-compressed on the way through.

Pages to remove

Type the pages you want gone on each file's row. Everything else is kept, in its original order.

3 drops one page  ·  2-4 drops three  ·  1,7-9 mixes the two  ·  2- drops page 2 to the end
